FileExt Admin

Connect to your GitHub repository to manage content. No server required — everything runs in your browser.

How to get a token:
  1. Go to github.com/settings/tokens
  2. Click Generate new token (classic)
  3. Give it a name (e.g. "FileExt Admin")
  4. Select scope: repo (full control)
  5. Click Generate and copy the token
