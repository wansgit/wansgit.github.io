How to Open HEIC Files on Windows: A Complete Guide

August 20, 2026 7 min read Adi Pratama
Tutorial

If you're an iPhone user, you may have encountered a situation where photos just taken from an iPhone can't be opened on a Windows computer. The file icon looks strange, and when you try to open it, an error message appears saying the file format is not supported. This happens because iPhones use an image format called HEIC (High Efficiency Image Container) that is not natively supported by the Windows operating system. Here's the story: my younger sister just bought an iPhone and sent vacation photos to the family group via WhatsApp. Everyone using Android could open the photos, except my father who uses a Windows laptop. The files couldn't be opened at all. In the end, I had to help remotely over the phone, explaining step by step how to open HEIC files on Windows. That's when I realized this problem is more common than I thought.

HEIC is an image format developed by Apple based on the HEVC (H.265) codec technology. This format was first introduced in iOS 11 in 2017 and has since become the default format for all photos taken using iPhones and iPads. HEIC offers several significant advantages over the traditional JPG format, including smaller file sizes and better quality. However, cross-platform compatibility remains a major challenge for this format.

In this complete guide, we'll discuss various ways to open, view, and convert HEIC files on Windows, using both built-in Windows tools, third-party applications, and online services. We'll also explain why HEIC became the default format on iPhones and whether it's worth changing your iPhone camera settings.

What Is the HEIC Format?

HEIC (High Efficiency Image Container) is an image container format that uses the HEVC (High Efficiency Video Coding) or H.265 codec for image compression. This format was developed by the Moving Picture Experts Group (MPEG) and adopted by Apple as the default format for photos on iOS and macOS devices starting in 2017.

HEIC has several important advantages over JPG:

  • Smaller file sizes: HEIC can produce file sizes 40-50% smaller than JPG with equivalent or even better quality. This means you can store more photos on your iPhone's memory.
  • Better quality: HEIC supports 10-bit color depth (1.07 billion colors) compared to 8-bit (16.7 million colors) in JPG. This produces smoother color gradients and better detail.
  • Transparency support: Just like PNG, HEIC supports alpha channel for transparency, which JPG does not have.
  • Storing multiple images: HEIC can store multiple images in a single file, such as burst photos or Live Photo images from iPhone.
  • Richer metadata: HEIC supports more complete metadata storage, including editing information that can be used to modify photos after they're taken.

Although HEIC offers many advantages, cross-platform compatibility remains an issue. Windows doesn't support the HEIC format natively, so Windows users need additional solutions to open and edit HEIC files.

Method 1: Install HEIC Image Extensions from Microsoft Store

The easiest and most official way to open HEIC files on Windows is to install HEIF Image Extensions from the Microsoft Store. Here are the steps:

  1. Open Microsoft Store on your Windows computer. You can find it in the Start Menu or taskbar.
  2. In the search bar, type "HEIF Image Extensions" and press Enter.
  3. Click the Install or Get button to install this application. This application is free to install.
  4. Wait until the installation process is complete. Once installed, you'll see a message that the installation was successful.
  5. Now try opening your HEIC file again. The file should now be able to be opened using the built-in Photos application on Windows.

This method is very easy and doesn't require any additional applications. However, keep in mind that there are two versions in the Microsoft Store: the free HEIF Image Extensions and the paid HEVC Video Extensions. To open HEIC photos, you only need the free HEIF Image Extensions.

Important: After installing HEIF Image Extensions, restart the Windows Photos application if the HEIC file still can't be opened. Sometimes Windows needs to be restarted for changes to take effect.

Method 2: Using Third-Party Photo Applications

If you prefer using third-party applications, there are several excellent free options:

I personally use IrfanView to open HEIC files because it's lightweight and can open almost every image format. But if you're looking for a more modern alternative, try XnView MP -- the interface is more intuitive and the features are more complete.

1. IrfanView

IrfanView is one of the most popular and lightweight image viewers for Windows. This application can open almost all image formats including HEIC. To open HEIC files in IrfanView, you need to install an additional HEIC/HEIF plugin available on the official IrfanView website. This plugin is free and easy to install.

2. XnView MP

XnView MP is a versatile image viewer that supports over 500 image formats including HEIC. This application can also be used to convert HEIC to other formats like JPG or PNG. XnView MP is available free for non-commercial use.

3. FastStone Image Viewer

FastStone Image Viewer is another lightweight alternative that supports the HEIC format. This application has an intuitive interface and basic editing features that are useful for home users.

4. Honeyview

Honeyview is a very fast image viewer that supports the HEIC format without needing to install additional plugins. This application is lightweight and doesn't burden the system.

All the applications above are free to use and offer more complete features compared to the built-in Windows Photos application. If you frequently work with various image formats, having one of these applications on your computer is highly recommended.

Method 3: Converting HEIC to JPG

If you want to convert HEIC files to JPG so they can be opened on all devices without issues, there are several methods available:

Using iCloud for Windows

If you have an iCloud account, you can enable the "Upload new photos from my PC" feature in iCloud settings. Photos from your iPhone will automatically be converted to JPG when synced to iCloud, and you can download them in JPG format from iCloud.com or iCloud for Windows.

Using iCloud.com

  1. Open your browser and visit iCloud.com
  2. Log in with your Apple ID
  3. Click the Photos icon
  4. Select the HEIC photos you want to convert
  5. Click the Download icon (cloud icon with a downward arrow)
  6. The photos will automatically be converted to JPG format when downloaded

Using Conversion Software

There are many free software programs that can convert HEIC to JPG in batch, meaning you can convert hundreds of photos at once. Some recommended software:

  • iMazing HEIC Converter: Free software specifically designed to convert HEIC to JPG with high quality. The interface is simple and easy to use.
  • CopyTrans HEIC: A plugin for Windows Explorer that allows you to right-click on a HEIC file and select a conversion option directly from the context menu.
  • Adobe Lightroom: If you already have an Adobe Creative Cloud subscription, Lightroom can open and convert HEIC files.

Using Online Tools

If you don't want to install additional software, there are several websites that can convert HEIC to JPG online:

  • heictojpg.com: A simple website that allows you to convert HEIC to JPG with drag and drop
  • convertio.co: A versatile online converter that supports many formats
  • cloudconvert.com: An online converter with adjustable quality options

Keep in mind that converting HEIC to JPG will slightly reduce image quality due to the lossy nature of JPG compression. However, the difference is usually not significant and is acceptable for most uses.

Method 4: Changing iPhone Settings

If you want to avoid HEIC compatibility issues in the future, you can change your iPhone camera settings to save photos in JPG format. Here's how:

  1. Open Settings on your iPhone
  2. Scroll down and select Camera
  3. Select Formats
  4. Select Most Compatible (the other option is High Efficiency which uses HEIC)

With this setting, all new photos taken will be saved in the universal JPG format. However, keep in mind that photos in JPG format will be larger in size than HEIC, so your iPhone's memory will fill up faster. If you have an iPhone with limited storage capacity, consider continuing to use the HEIC format and converting when needed.

HEIC vs JPG: Which Is Better?

This question frequently comes up among iPhone users. Let's compare both formats objectively to help you make the right decision about which format to use.

In terms of quality, HEIC is superior because it supports higher color depth (10-bit vs 8-bit in JPG), resulting in smoother color gradients and richer detail. In terms of file size, HEIC is also more efficient because it can produce file sizes 40-50% smaller than JPG with equivalent quality. However, in terms of compatibility, JPG is still the king because it's supported by virtually all devices and applications worldwide.

So, if you always work within the Apple ecosystem (iPhone, iPad, Mac), using HEIC is the right choice because all Apple devices already support this format perfectly. However, if you frequently share photos with Windows users or need to upload photos to websites that don't support HEIC, consider using JPG format or converting HEIC to JPG when needed.

Troubleshooting: Common Issues with HEIC Files

Here are some common issues users often face with HEIC files along with their solutions:

  • HEIC file can't be opened even after installing HEIF Extensions: Try restarting your computer. If it still doesn't work, make sure you installed the correct version (HEIF Image Extensions, not HEVC).
  • HEIC thumbnails not visible in File Explorer: Install HEIF Extensions from the Microsoft Store, then restart Explorer or your computer.
  • Adobe Photoshop can't open HEIC: Make sure you're using Photoshop CC 2017 or later. Older versions don't support HEIC.
  • HEIC file is corrupted or damaged: Try opening the file on another device or use repair software like Stellar Repair for Photo.
  • HEIC to JPG conversion is very slow: This usually happens when converting many files at once with high resolution. Try converting in smaller batches.

Conclusion

The HEIC format does offer many advantages in terms of quality and storage efficiency, but cross-platform compatibility remains a challenge, especially for Windows users. With the various methods we've explained above, you now have several options for opening, viewing, and converting HEIC files on Windows according to your needs and preferences.

Whether you choose to install HEIF Extensions from Microsoft Store, use third-party applications like IrfanView, or convert HEIC to JPG using online tools, the most important thing is that you have the right solution to overcome HEIC compatibility issues.
